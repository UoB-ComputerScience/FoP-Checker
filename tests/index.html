Checker development tests

From the repository root, run npm ci --ignore-scripts --omit=optional, then npm test (Node 22.18 or later). This prepares the browser libraries and runs the ZIP regression tests and site build check.

The regression suites need the private examples in .FoP-TestFiles/, a local folder beside this repository. Expected findings are recorded in tests/fixtures.json.

For browser tests, run the local helper python .local/tools/serve.py and open the address it prints. Stop it with Ctrl+C.

  • Generated examples — archive, project and report workers.
  • Report regression tests — synthetic cases and private reports.
  • PDF regression tests — readability, text and limits.

Optional fixture generators and other Python helpers are kept locally in the ignored .local/tools/ folder. They are not part of the application or included in the repository; use each helper's --help for its options. A fresh checkout needs those local files to run these suites.
